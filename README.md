# 电商视觉生成工具（EC Visual Generator）

用于整理电商产品视觉生成规范、提示词模板与辅助脚本，并沉淀 TESNA 的实际工作流。

> **先看这里：** 如果你目前只想在 ChatGPT 网页中策划和逐张生成电商图片，请先阅读 `workflow/` 中的 TESNA 标准工作流。仓库中的 Python 脚本属于另一条本地/接口执行路线，不代表网页端已经部署了自动化服务。

## 从哪里开始

### 我只想按工作流制作 TESNA 电商图

1. 阅读 [TESNA 电商视觉工作流（标准版 v1.0）](workflow/TESNA电商视觉工作流_标准版_v1.0.md)。
2. 新品开始时先确认目标平台、产品真实图片、已确认参数和本次图片用途。
3. 先规划整套图片与视觉风格；默认逐张生成、逐张确认。
4. 产品外观、Logo、型号和参数必须以真实资料为准。未经确认的功能不能写进正式宣传图。

### 我想了解仓库里的 Skill 和代码

1. 阅读 [SKILL.md](SKILL.md)：了解设计目标、输入参数、预期输出和技术依赖。
2. 查看 [scripts/](scripts/)：了解生成、提示词构建、图片合成和文件整理相关脚本。
3. 查看 [templates/](templates/)：了解主图、详情页、广告布局和卖点模板。
4. 运行任何脚本前，先检查依赖、路径、API 配置和实际执行环境；不要把文档中的示例路径或命令视为在所有电脑上都能直接运行。

## 重要边界

- **工作流文档不等于已部署的软件。** `workflow/` 用于指导实际制作流程；`scripts/` 是代码，需要匹配的运行环境。
- **本地脚本路线有技术依赖。** 请先查看 `SKILL.md` 中的 Python、图像处理库及 AI 接口要求。
- **不要把未经核实的参数写进产品图。** 蓝牙版本、降噪、防水、续航、认证等均须有确认依据。
- **产品一致性优先。** 产品结构、颜色、材质和 Logo 应以用户提供的真实参考图为准；生成后需检查变形。
- **暂不删除历史内容。** 目录调整应先确认文件用途和依赖，避免破坏脚本引用或丢失原始资料。

## 当前整理原则

1. 先让仓库入口清楚，再考虑目录迁移。

5. 后续若增加项目资料，优先按“规范 / 代码 / 模板 / 工作流”归类，不要把所有内容都堆在仓库根目录。
